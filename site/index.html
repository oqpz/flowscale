How it works

No game files are touched. FlowScale captures the window, processes it on your GPU and shows the result on top.

Run your game windowed

Windowed or borderless, not exclusive fullscreen. A lower resolution than your screen gives the upscaler room to help.

Pick a preset

Smooth 2x + FlowSharp is a good start. Save a profile per game and it can kick in automatically.

Press Scale

Or Ctrl+Alt+S, then click into the game. Press it again to stop.

What you get

FlowGen 3 estimates motion between two real frames and draws the ones in between, at a fixed multiplier or holding a target like 144 FPS.

Upscaling

FlowSharp, FSR 1, NIS, SGSR, Anime4K, xBR for pixel art, and plain integer scaling.

Three capture modes

DXGI is the fastest. Windows Graphics Capture handles HDR and awkward borderless windows.

Per-game profiles

Match a game's .exe and FlowScale starts a few seconds after you switch to it.

A log that explains itself

Captured vs generated FPS, dropped frames and GPU time, with a hint when your settings are too heavy.

Questions

Windows says the app is unrecognized. Is it safe?

The exe isn’t code-signed yet, so SmartScreen warns about it. Click More info then Run anyway. The full source is on GitHub if you’d rather build it yourself.

Does it work in exclusive fullscreen?

No. Windows can’t capture exclusive fullscreen the way FlowScale needs, so switch the game to windowed or borderless.

Will it get me banned?

FlowScale doesn’t inject into or modify games; it only captures the window like a recording app does. Still, anti-cheat rules vary by game, so check if you play competitively.

Generated frames look smeary or my FPS dips.

Open Log. If generation time is close to the frame budget, lower Flow scale from 100% to 50%. It cuts the GPU cost of frame generation by about four times.

Does it add input lag?

Some. Generated frames need the next real frame first, so expect roughly one game frame of extra delay. It feels smoother but isn’t faster.
